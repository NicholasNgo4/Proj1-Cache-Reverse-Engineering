# Competition 1 — Reverse-Engineering Scorecard

One row per candidate machine–property result. A claimed number alone does not count —
each row needs the microbenchmark/code, raw data, an evidence plot/table, an inference
rule, and (when available) Phase-II verification.

**Countable property examples:** L1/L2/LLC capacity, line size, associativity/effective
associativity, number of sets, L1/L2/LLC hit latency, next-level/memory latency (miss
penalty), cache-sharing scope, inclusion/exclusion behavior.

**Does NOT count:** repeated claims, one result artificially split into multiple rows,
or unsupported/specification-derived values.
